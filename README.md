# 이음 디자인 라이브러리

인스타그램 피드 · 워크시트 · 교재 · 저술 · 블로그 템플릿을 모은 공개 갤러리입니다.

**공개 페이지:** https://kingspledu.github.io/ieum-template-gallery/

## 기능

- 5개 카테고리, 총 24개 템플릿
- BrightIdeas 캐러셀 템플릿 9장과 편집 가능한 PPTX
- 문구·색상 편집, 사진 업로드, PNG·HTML·JSON 내보내기
- 이미지 13개 영역의 주제별 메타 프롬프트
- 카테고리 추가, 즐겨찾기, 브라우저 저장과 JSON 백업

## 데이터

- [전체 템플릿](templates.json)
- [이미지 메타 프롬프트](download/image-meta-prompts.md)
- [메타 프롬프트 JSON](download/image-meta-prompts.json)

이 저장소는 서버와 의존성 없이 GitHub Pages로 배포됩니다. 이미지 생성 모델 또는 MCP 서버가 포함되어 있지는 않습니다. 에이전트는 공개 JSON을 읽어 활용할 수 있습니다.

## 편집과 저장

index.html 안의 CSS와 JavaScript를 수정해 페이지를 업데이트할 수 있습니다. 기본 템플릿 데이터는 페이지 내 base 배열과 templates.json에 있습니다. 내 템플릿, 카테고리와 업로드 사진은 방문자의 브라우저에만 저장됩니다. 중요한 작업은 JSON으로 백업하세요. 사이트 주소가 달라지면 기존 브라우저 저장 데이터는 자동으로 이전되지 않으므로 이전 사이트에서 백업 후 가져오기를 사용하세요.

PPTX와 PNG 묶음은 기본 디자인 파일입니다. 웹에서 편집한 내용이 PPTX에 자동으로 반영되지는 않습니다. 교재와 학생 글은 사진을 넣을 수 있는 빈 영역이며 실제 학생 자료로 오인하지 않도록 구성했습니다.

## 여러 페이지 묶음

카드의 묶기 체크박스로 템플릿을 고른 뒤 상단 페이지 묶음을 누르세요. 캐러셀 9장으로 바로 시작할 수도 있습니다. 페이지 순서 변경, 복제, 제거와 개별 문구·사진 편집을 지원합니다. 공통 브랜드, 하단 문구, 색상, 이미지 주제와 찾기/바꾸기를 한 번에 적용할 수 있습니다.

묶음은 브라우저에 저장하거나 JSON으로 백업하고 다시 불러올 수 있습니다. PNG 전체 ZIP, 통합 HTML, 묶음 JSON과 이미지 프롬프트 JSON을 내보냅니다. 한 묶음은 최대 60페이지이며, 동적으로 편집한 묶음의 PPTX 변환은 포함하지 않습니다.
