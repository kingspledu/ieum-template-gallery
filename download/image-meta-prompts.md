# 새 주제용 이미지 메타 프롬프트

주제, 대상 학습자, 핵심 개념, 스타일을 바꿔 사용합니다.

- 메타 프롬프트는 텍스트 AI에 전달해 구체적인 장면과 완성 프롬프트를 설계합니다.
- 이미지 프롬프트는 주제와 장면을 채워 이미지 생성 도구에서 사용합니다.
- 제목과 긴 문구는 생성 이미지에 그리지 않고 편집기에서 따로 배치합니다.
- 실제 학생 작업물 대신 생성 예시를 쓰면 외부 캡션에 예시임을 표시합니다.
- 같은 시리즈에는 동일한 주제·스타일·팔레트·seriesKey를 사용합니다.

### 메타 프롬프트

```text
당신은 교육 자료와 인스타그램 캐러셀의 이미지 아트디렉터입니다. 아래 입력을 해석해 새 주제에 맞는 이미지 생성 프롬프트를 작성하세요.

입력값:
{
  "topic": "{{주제}}",
  "audience": "초등 고학년~중학생",
  "focus": "{{주제에서 강조할 핵심 개념·상황}}",
  "category": "모바일에서 한눈에 읽히는 인스타그램 캐러셀",
  "slot": "워크시트 사진",
  "role": "worksheet",
  "style": "차분한 실사 목업",
  "palette": [
    "#302963",
    "#F5B92D",
    "#FFFFFF"
  ],
  "aspectRatio": "49:64",
  "seriesKey": "ieum-instagram-{{주제}}"
}

작업 순서:
1. 주제를 대상 학습자가 이해할 핵심 개념 2~3개로 풀어 쓰세요.
2. 그 개념을 보여 주는 구체적인 사물·장소·행동을 정하세요. 입력의 focus가 비어 있거나 {{ }} 변수이면 주제와 학습 수준에 맞는 장면을 제안하세요.
3. 이 이미지 영역의 역할을 지키세요: 새 주제로 만든 워크시트 예시를 위에서 내려다본 정갈한 자료 사진. 제목 영역, 질문 블록, 답을 적을 공간을 구분한다. 주제와 관련된 작은 개념 그림을 배치한다. 글자는 읽히지 않는 짧은 선으로 표현하며 문제와 정답은 편집기에서 별도로 넣는다. 이 영역은 학습 계획과 핵심 어휘를 소개하는 첫 자료 역할을 맡는다.
4. 시리즈 전체에서 같은 색감, 광원, 배경 질감, 시점과 피사체 비율을 유지한다. 이전 주제의 피사체를 그대로 두지 말고 새 주제의 구체적인 장면으로 바꾼다. 화면 중앙 80% 안에 핵심 피사체를 배치해 잘림에 대비하고 가장자리 10%는 여유를 둔다. 제목·학원명·CTA·긴 문장·로고·워터마크는 이미지에 그리지 않는다. 텍스트는 편집 가능한 별도 레이어로 배치한다.
5. 실사 목업을 선택했다면 자연스러운 종이 질감과 부드러운 확산광을, 일러스트를 선택했다면 일관된 선 두께와 단순한 면을 사용하세요.
6. 실제 학습 증거가 필요한 자리에는 원본 사진을 우선하고, 생성 이미지를 쓰면 반드시 예시임을 외부 캡션에 표시하세요.

출력은 JSON 하나로 작성하세요: {"slotKey":"worksheetLeft","topicInterpretation":"주제를 시각화한 이유","imagePrompt":"이미지 생성 모델에 바로 넣을 완성 프롬프트","negativePrompt":"피할 요소","alt":"그림 설명","overlayText":[],"disclosure":"AI로 생성한 예시 이미지입니다."}. 비율은 49:64이고 권장 크기는 1225×1600입니다. 이미지 안에 정확한 텍스트가 필요하면 overlayText에만 제안하세요. 이미지 생성 모델이 지원하지 않는 옵션이나 특정 시드를 약속하지 마세요.
```
